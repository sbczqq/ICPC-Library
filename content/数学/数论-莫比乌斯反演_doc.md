## 数论 - 莫比乌斯反演

### 核心结论

* **莫比乌斯函数**：$\mu(1)=1$；含有平方质因子的数，$\mu(n)=0$；其余数若有 $t$ 个不同质因子，则 $\mu(n)=(-1)^t$。
* **约数求和**：$\sum_{d\mid n}\mu(d)$ 在 $n=1$ 时为 $1$，在 $n>1$ 时为 $0$。例如 $\mu(6)=1$、$\mu(12)=0$。
* **反演公式**：若 $F(n)=\sum_{d\mid n}f(d)$，则 $f(n)=\sum_{d\mid n}\mu(d)F(n/d)$。

### 使用方法

* **初始化**：调用 `init(N)`，线性筛出 $1\sim N$ 的 `mu`，同时计算前缀和 `su`；`N` 为正整数，且至少覆盖后续调用中最大的 `min(n,m)`。多次查询可以统一预处理一次。
* **统计互质数对**：调用 `cal(n,m)`，返回满足 $1\le a\le n$、$1\le b\le m$、$\gcd(a,b)=1$ 的有序数对数量。例如 `cal(6,6)` 返回 `23`，其中 `(1,2)` 与 `(2,1)` 分别计数。
* **统计最大公约数为 k 的数对**：先令 `n/=k`、`m/=k`，再调用 `cal(n,m)`。代码中的 `solve()` 读入正整数 `n,m,k` 并输出结果；缩小后的任意范围为 $0$ 时，直接输出 $0$。

```cpp
init(min(n,m)); // 预处理本次互质计数所需的范围
int an=cal(n,m); // 统计两个范围内的互质有序数对
```

### 计数原理

利用约数求和性质，对每个数对枚举其公约数 $d$：互质时贡献 $1$，不互质时总贡献为 $0$。交换求和顺序后得到：

$$\operatorname{cal}(n,m)=\sum_{d=1}^{\min(n,m)}\mu(d)\left\lfloor\frac{n}{d}\right\rfloor\left\lfloor\frac{m}{d}\right\rfloor$$

固定区间左端点 `l`，令 `x=n/l`、`y=m/l`，则两个商同时不变的最远右端点为 `r=min(n/x,m/y)`。这一段的贡献合并为 `(su[r]-su[l-1])*x*y`，然后跳到 `r+1`。

### 复杂度

* **预处理**：时间 $O(N)$，空间 $O(N)$。
* **单次查询**：整除分块，时间 $O(\sqrt n+\sqrt m)$，额外空间 $O(1)$；这里的 $n,m$ 为传入 `cal` 的范围。
