## 数学 - 任意模数多项式乘法 (MTT / 三模数 NTT)

### 1. 什么时候用（触发条件）
当且仅当同时满足以下 **3 个条件**时，掏出此模板：
1. **题型**：需要求多项式乘法 / 序列卷积（如 $C_k = \sum A_i \times B_{k-i}$）。
2. **模数非 NTT 素数**：题目给定的模数（如 $10^9+7$ 或任意合数）无法使用标准 NTT。
3. **数据极大**：序列长度 $\ge 10^5$，原系数达到 $10^9$。此时绝对真实结果峰值达 $10^{23}$，使用复数 FFT + 取模必定引发 `long double` 精度丢失（WA）。

### 2. 核心参数
* **时间复杂度**：$O(N \log N)$（常数约为普通 NTT 的 9 倍，注意卡常）。
* **御用三模数**：$P_0 = 998244353$，$P_1 = 1004535809$，$P_2 = 469762049$（原根均为 $G=3$）。三者乘积 $> 10^{26}$，足以覆盖 $10^{23}$。

---

### 3. 怎么用（5 步执行逻辑）

不要管底层数学，直接按以下顺序拼接代码：

* **Step 1【复制】**：将输入的原始多项式 $A$、$B$，各自复制 3 份存入 `a[0~2][i]` 和 `b[0~2][i]`。
* **Step 2【初始化】**：求出首个 $\ge n+m+1$ 的 2 的次幂 `tot`，并递推求出位逆序数组 `rev`。
* **Step 3【常数预处理】**：
  * `inv1` = $P_0$ 在模 $P_1$ 下的逆元。
  * `inv12` = $(P_0 \times P_1) \pmod{P_2}$ 在模 $P_2$ 下的逆元。
* **Step 4【三次独立 NTT】**：循环 $k \in [0, 2]$，在模数 $P_k$ 下独立执行：
  1. 正向 NTT：`ntt(a[k], 1, P[k])` 与 `ntt(b[k], 1, P[k])`。
  2. 点值相乘：`a[k][i] = a[k][i] * b[k][i] % P[k]`。
  3. 逆向 NTT：`ntt(a[k], -1, P[k])`。
  4. 乘逆元：结果逐项乘以 `tot` 在模 $P_k$ 下的逆元。
* **Step 5【CRT 组合取模】**：遍历结果数组的每一项 $i$，调用 `CRT(a[0][i], a[1][i], a[2][i], target_mod)`：
  1. **一阶合并**：$x_{12} = \text{合并方程 } P_0 \text{ 和 } P_1$（用 `inv1`，使用 `long long`）。
  2. **二阶合并**：$\text{Ans} = \text{合并方程 } x_{12} \text{ 和 } P_2$（用 `inv12`，**必须强制转为 `__int128`**）。
  3. **输出**：返回 $\text{Ans} \pmod{target\_mod}$ 作为该项最终结果。
