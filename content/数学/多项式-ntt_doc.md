## 多项式 - NTT (快速数论变换)

### 算法说明

* **用途**：快速计算多项式乘积，结果对 `998244353` 取模。
* **核心思想**：用模意义下的单位根完成正逆变换，点值相乘后恢复系数。
* **复杂度**：时间 $O(n\log n)$，空间 $O(n)$，$n$ 为补齐后的变换长度。

### 使用方法

* 系数从常数项到最高次项存入非空数组，调用 `mul(a,b)`，返回 `a.size()+b.size()-1` 个系数，负系数自动转为合法余数。
* 固定 `mod=998244353`、原根 `g=3`，补齐后的变换长度必须不超过 $2^{23}$。

```cpp
vector<int>a={1,2},b={3,4}; // 1+2x与3+4x相乘
vector<int>ans=mul(a,b); // {3,10,8}，所有系数对mod取模
```

### 与FFT的区别

* **精度与结果**：NTT做整数模运算，模意义下结果精确；FFT做浮点运算，本仓库FFT模板将结果四舍五入为普通整数。
* **模数限制**：变换长度必须整除 `mod-1`。当前模数满足 $998244353-1=119\times2^{23}$，不能直接改成 `1e9+7` 沿用本模板。
* **如何选择**：要求模 `998244353` 时用NTT；需要普通整数卷积且精度足够时用FFT。单模NTT不能直接恢复超过模数范围的普通整数系数。
