## 多项式 - FFT (快速傅里叶变换)

### 算法说明

* **用途**：快速计算多项式乘积，本模板返回整数系数卷积。
* **核心思想**：系数转为点值，对应相乘，再逆变换恢复系数。
* **复杂度**：时间 $O(n\log n)$，空间 $O(n)$，$n$ 为补齐后的变换长度。

### 使用方法

* 系数从常数项到最高次项存入非空数组，调用 `mul(a,b)`，返回 `a.size()+b.size()-1` 个系数。
* 函数自动补0到2的幂，使用 `double` 计算，最后四舍五入为整数；支持负系数。

```cpp
vector<int>a={1,2},b={3,4}; // 1+2x与3+4x相乘
vector<int>ans=mul(a,b); // {3,10,8}，即3+10x+8x²
```

### 与NTT的区别

* **运算方式**：FFT使用复数和浮点运算，NTT使用模运算，模意义下没有浮点误差。
* **结果含义**：本模板返回普通整数系数，NTT返回系数对 `998244353` 取模的结果。
* **如何选择**：普通整数卷积且精度足够时用FFT；题目要求模 `998244353` 时用NTT。FFT的系数或结果较大时可能舍入失准，不能保证任意 `long long` 系数都精确。
