## 组合数学 - 广义卡特兰数

### 计数的问题

余额从0开始，安排下面两种操作的顺序：

* **A：加1**，共 `(k-1)*n` 次。
* **B：减去k-1**，共 `n` 次。
* **要求**：任何时刻余额都不能为负。同类操作不区分，问有多少种合法顺序。

当 `k=2` 时，两种操作就是 `+1、-1`，退化为普通卡特兰数。一般的答案为：

$$F_k(n)=\frac{1}{(k-1)n+1}\binom{kn}{n}$$

### 一个例子

`n=2、k=3`：4次加1、2次减2，合法顺序有3种：

```text
AAAABB
AAABAB
AABAAB
```

例如 `AABAAB` 的余额依次为 `1、2、0、1、2、0`，始终非负；以 `AB` 开头则会变成 `1、-1`，不合法。

### 使用方法

```cpp
init(6); // 预处理到最大k*n，范围小于固定质数模1e9+7
int a=catalan(2); // k默认是2，答案2
int b=catalan(2,3); // 对应上例，答案3
```

要求 `n>=0、k>=2`，结果对 `1e9+7` 取模。预处理 $O(M+\log mod)$，单次计算 $O(\log mod)$，空间 $O(M)$。

参考：[广义卡特兰公式](https://arxiv.org/abs/0711.0906)。
