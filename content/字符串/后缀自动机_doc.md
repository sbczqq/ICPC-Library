## 字符串 - 后缀自动机 (SAM)

### 算法说明

* **用途**：维护一个串的所有子串，支持统计不同子串数量、查询子串出现次数。
* **状态含义**：结束位置集合相同的子串合并为一个状态。例如 `ababa` 中，`b` 和 `ab` 都在位置2、4结束，所以共用状态。
* **复杂度**：固定26个小写字母时，构建 $O(n)$，查询长度为 $m$ 的串为 $O(m)$，转移表空间 $O(26n)$。

### 关键字段

* **`ch[c]`**：追加字符 `c` 后到达的状态，0表示不存在。
* **`len`**：当前状态代表的最长子串长度。
* **`link`**：指向最长的、属于另一个状态的真后缀所在状态。
* **`occ`**：完成次数传播后，当前状态中每个子串的出现次数。

1为根，`last` 为整个当前字符串对应的状态。非根状态 `p` 代表长度在 `len[link[p]]+1..len[p]` 之间的子串，每个长度恰好一个。

### 核心过程

1. 添加字符时建立新状态 `cur`，令 `len` 加1、`occ=1`，沿后缀链接补齐缺失转移。
2. 遇到已有转移 `p→q`：若 `len[p]+1==len[q]`，直接连接；否则克隆 `q`，缩短克隆的 `len`，调整转移和后缀链接。
3. 克隆的 `occ=0`，因为它只拆分状态，没有新增结束位置。构建后按 `len` 从长到短执行 `occ[link[p]]+=occ[p]`，统计真实出现次数。

**克隆例子**：`ab` 中的 `b、ab` 都只在位置2结束；追加 `b` 后，`b` 在位置2、3结束，`ab` 仍只在位置2结束，因此要拆成不同状态。

### 使用与例子

模板处理长度不超过20万的非空小写字母串，查询串也须非空且为小写字母。

```cpp
build("ababa"); // 构建并完成次数统计
cout<<distinct()<<endl; // 9种不同的非空子串
cout<<query("aba")<<endl; // 出现2次，重叠也计算
cout<<query("c")<<endl; // 没有出现，输出0
```

CPP输入原串、询问数和各查询串；先输出不同子串数量，再逐行输出各串的出现次数。

### 常用结论

* **不同子串数量**：对非根状态累加 `len[p]-len[link[p]]`。
* **最长重复子串长度**：在 `occ>=2` 的状态中取最大的 `len`。
