## 连通 - 点双连通分量

### 算法说明

* **用途**：将无向图分为若干块，每块内部没有割点，块与块可以通过割点连接。
* **关键判断**：DFS树边 `u→v` 满足 `low[v]>=dfn[u]`，弹栈到 `v`，再加入 `u`，得到一个点双；`u` 留在栈中参与其他分量。
* **结果**：`cnt` 为点双数量，`bcc[k]` 为第 `k` 组的点，`cut[u]` 标记割点。割点可属于多组，不能用唯一的 `id[u]` 表示归属。
* **复杂度**：时间、工作空间均为 $O(n+m)$。

### 使用方法

```cpp
add(u,v,i); // 第i条无向边只调用一次，编号从1开始，重边编号不同
vbcc(n); // 全部边加入后调用，自动处理不连通的图
int size=bcc[k].size(); // 第k个点双的点数
bool a=cut[u]; // 点u是否为割点
```

例如三角形 `{1,2,3}` 和 `{3,4,5}` 共用点3，点双为这两组，割点3同时属于两组。

桥的两个端点组成一个两点分量，孤立点单独一组，自环不另建分量。更换原图时另行清空 `g`。
