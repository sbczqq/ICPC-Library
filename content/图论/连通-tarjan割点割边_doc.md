## 连通 - Tarjan割点割边

### 算法说明

* **用途**：在无向图中找割点和割边。删除它们后，连通块数量会增加。
* **割边**：DFS树边 `u→v` 满足 `low[v]>dfn[u]`，则这条边是桥。
* **割点**：非根存在子节点满足 `low[v]>=dfn[u]`；根则必须有至少两个DFS子节点。
* **复杂度**：时间、工作空间均为 $O(n+m)$，支持重边和自环。

### 使用方法

```cpp
add(u,v,i); // 第i条无向边，只调用一次，i为1..m中的唯一编号
cutbridge(n,m); // 全部边加入后调用，自动处理各个连通块
bool a=cut[u]; // 点u是否为割点
bool b=br[i]; // 第i条边是否为割边
```

例如 `1—2—3`，点2是割点，两条边都是桥。DFS跳过进入边的编号，不能跳过所有通向父节点的边。更换原图时另行清空 `g`。
