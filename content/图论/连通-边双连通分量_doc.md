## 连通 - 边双连通分量

### 算法说明

* **用途**：删除无向图中的所有桥，剩余的每个连通块就是一个边双；块内不会因删除一条边而断开。
* **关键判断**：`dfn[u]==low[u]` 时弹栈到 `u`，得到一个边双；DFS树边满足 `low[v]>dfn[u]` 时标记为桥。
* **结果**：`id[u]` 为点所属分量，`bcc[k]` 为各组点集，`cnt` 为分量数量，`br[i]` 为桥标记，`ne` 为桥连接各组形成的森林。
* **复杂度**：时间、工作空间均为 $O(n+m)$，支持重边和自环。

### 使用方法

```cpp
add(u,v,i); // 第i条无向边只调用一次，i为1..m中的唯一编号
ebcc(n,m); // 全部边加入后调用，自动处理各个连通块
bool same=id[u]==id[v]; // 两点是否属于同一个边双
bool a=br[i]; // 第i条边是否为桥
```

例如两个三角形 `{1,2,3}`、`{4,5,6}` 由边 `3—4` 连接，得到两个边双，缩点后由这条桥相连。

每个点只属于一个边双，孤立点单独一组；点双中的割点则可能属于多组。更换原图时另行清空 `g`。
