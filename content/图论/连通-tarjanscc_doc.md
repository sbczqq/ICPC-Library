## 连通 - Tarjan SCC (强连通分量与缩点)

### 算法说明

* **用途**：在有向图中，将能够互相到达的点分为一组，再将每组缩成一个点。
* **关键判断**：`dfn[u]==low[u]` 时，从栈顶弹到 `u`，得到一个强连通分量；已访问的邻点只有仍在栈中时才能更新 `low`。
* **结果**：`id[u]` 为所属分量，`cnt` 为分量数量，`ne` 为缩点后的DAG，平行边不去重。
* **复杂度**：时间、工作空间均为 $O(n+m)$。

### 使用方法

```cpp
e[u].push_back(v); // 添加有向边u→v
scc(n); // 全部边加入后调用，自动处理不连通的图
bool same=id[u]==id[v]; // 是否属于同一个强连通分量
```

例如 `1→2、2→1、2→3`，分为 `{1,2}` 和 `{3}`，缩点后前一组指向后一组。重新计算会清空结果；更换原图时另行清空 `e`。
