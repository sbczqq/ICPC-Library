# 数据结构/图论 - 重链剖分 (树链剖分 / HLD) 

### 何时使用
树上**带修改**的路径/子树操作（如：$u$ 到 $v$ 路径集体加 $k$、求子树权值和）。

### 核心步骤
1. **`dfs1`**：求深度 `dep`、父亲 `fa`、子树大小 `sz`，并选出重儿子 `son`。
2. **`dfs2`**：连重链，求顶点 `topf`，分配连续的 DFS 序 `dfn`（**必须优先走重儿子**）。
3. **`build`**：用映射后的 `dfn` 数组建立线段树。
4. **路径操作**：比较两点所在重链顶点 `topf` 的深度，**深者先往上跳**，边跳边用线段树处理该段重链区间。
