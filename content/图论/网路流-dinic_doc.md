## 图论 - 网络流 Dinic (最大流)

### 使用方法

* **初始化**：用 `Dinic dinic(n)` 建立一张有 $n$ 个点的网络，点编号为 $1 \sim n$；指定源点 `s` 和汇点 `t`。
* **加边**：对原图的每条有向边调用 `dinic.add(u,v,ca)`，表示从 `u` 到 `v` 最多通过 `ca` 单位流量。函数会自动添加初始容量为 $0$ 的反向边，用于在增广时调整已有流量。
* **求最大流**：建图后调用 `dinic.maxflo(s,t)`，返回从源点到汇点的最大流。容量和流量使用 `long long`。
* **残量网络**：计算过程中，`e[id].cap` 保存该边的剩余容量；正向边和反向边的编号互为 `id ^ 1`。再次调用 `maxflo(s,t)` 会从当前残量网络继续增广，返回本次新增的流量。

```cpp
Dinic dinic(n); // 初始化 n 个点
dinic.add(u,v,ca); // 对原图的每条有向边执行一次
int ans=dinic.maxflo(s,t); // 得到 s 到 t 的最大流
```

### 核心步骤

1. **BFS 分层**：通过剩余容量大于 $0$ 的边计算 `dep`，得到源点到各点的层数。
2. **DFS 增广**：只沿层数增加 $1$ 的边发送流量，同时减少正向边容量、增加反向边容量；`cur` 记录当前搜索位置，减少重复扫描。
3. **重复分层**：当前分层图无法继续发送流量后重新 BFS，直到汇点不可达。

### 复杂度

* **时间复杂度**：一般网络为 $O(V^2E)$，其中 $V$ 为点数，$E$ 为原图边数。
* **空间复杂度**：$O(V+E)$。
