## 算法基础 - 边差分

### 算法说明

* **用途**：多次给树上一条路径的所有边加权，最后统一求每条边的增量。
* **标记**：令 `p=lca(u,v)`，两端各加 `w`，`p` 减 `2*w`。
* **汇总**：所有修改结束后调用一次 `collect()`，最终 `d[u]` 表示边 `(u,fa[u][0])` 的增量，根没有父边。
* **复杂度**：预处理 $O(n\log n)$，单次修改 $O(\log n)$，最后汇总 $O(n)$。

### 使用与例子

建好邻接表 `e` 后调用 `init()`；代码已包含LCA预处理，`d` 初始为0，用较深的端点表示一条边。

```text
  1
 / \
2   3
```

```cpp
init(); // 已建好下面的小树
update(2,3,5); // 路径2→1→3上的两条边各加5
collect(); // 得到d[2]=5、d[3]=5，分别对应1—2、1—3；d[1]=0
```

**为什么减两份？** 两端的贡献在LCA处汇合，需要全部抵消，因为LCA通向父节点的边不在路径上。`u=v` 时没有边，贡献为0。

CPP输入 `n,m`、`n-1` 条边，再输入 `m` 组 `u,v,w`；按道路输入顺序逐行输出最终边权。

参考：[OI Wiki：树上差分](https://oi-wiki.org/basic/prefix-sum/#树上差分)。
