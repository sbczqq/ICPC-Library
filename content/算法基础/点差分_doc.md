## 算法基础 - 点差分

### 算法说明

* **用途**：多次给树上一条路径的所有点加权，最后统一求每个点的增量。
* **标记**：令 `p=lca(u,v)`，两端各加 `w`，`p` 和 `p` 的父节点各减 `w`。
* **汇总**：所有修改结束后调用一次 `collect()`，子节点贡献累加给父节点，最终 `d[u]` 就是点 `u` 的增量。
* **复杂度**：预处理 $O(n\log n)$，单次修改 $O(\log n)$，最后汇总 $O(n)$。

### 使用与例子

建好邻接表 `e` 后调用 `init()`；代码已包含LCA预处理，`fa[u][0]` 为父节点，`d` 初始为0。

```text
  1
 / \
2   3
```

```cpp
init(); // 已建好下面的小树
update(2,3,5); // 路径2→1→3上的点全部加5
collect(); // 修改全部结束后汇总，得到d[1]=d[2]=d[3]=5
```

**为什么要减父节点？** LCA本身需要保留一份；在其父节点再减一份，才不会继续影响路径以外的祖先。

CPP输入 `n,m`、`n-1` 条边，再输入 `m` 组 `u,v,w`；输出各点的最终权值。

参考：[OI Wiki：树上差分](https://oi-wiki.org/basic/prefix-sum/#树上差分)。
